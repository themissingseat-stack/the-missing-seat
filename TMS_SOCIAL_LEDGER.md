# TMS social publication ledger

Created November 15, 2026. This file records what has happened to the Facebook and Instagram teaser for each published story, so nobody has to guess from the website record.

**Status values, in order:** `needed` (no draft) → `drafted` → `approved` (Jansen OK'd the text) → `scheduled` → `published` (Jansen confirms it is actually on the account). `skip` means no post is wanted. `unknown` means nobody has checked the actual account yet. Only Jansen can move a post to `published`. Never infer it from a draft existing.

**Platforms:** FB = Facebook, IG = Instagram. EN = English, DE = German. German posts are only for Germany-focused stories. One country per post.

**Rules:** see TMS_EDITORIAL_STANDARD.md and the November 4, 2026 brand and endings standard. Plain text, no hashtags, emojis, em dashes or signature line by default.
