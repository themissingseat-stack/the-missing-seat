Files included:
- index.html
- style.css
- assets/the-chair.svg

How to publish on Cloudflare Pages:
1. Log into Cloudflare.
2. Go to Workers & Pages.
3. Click Create application.
4. Choose Pages.
5. Choose Upload assets / Direct upload.
6. Upload the CONTENTS of this folder, not just the folder itself.
7. Deploy the project.
8. In the Pages project, go to Custom domains.
9. Add themissingseat.org.
10. Cloudflare will connect the domain automatically if it is registered in the same account.

Suggested project name: the-missing-seat
